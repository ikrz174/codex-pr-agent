# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability in **Codex PR Agent**, please report it responsibly:

1. **Do not** open a public GitHub issue for sensitive security vulnerabilities.
2. Open a private security advisory via GitHub Security Advisories, or email `namdar.vali@gmail.com` with:
   - Description of the vulnerability
   - Steps to reproduce
   - Potential impact and suggested remediation (if any)

We aim to acknowledge all security reports within 48 hours and release patches promptly for confirmed issues.
